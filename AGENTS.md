# Portfolio Project Instructions

## Technology
- Use Next.js App Router.
- Use React, TypeScript, and Tailwind CSS.
- Keep components reusable and clearly named.
- Do not add production dependencies unless necessary.
- Prefer CSS and Tailwind for simple animation.

## Current Phase
- We are currently designing the visual prototype.
- Do not add real personal information yet.
- Use realistic placeholder content.
- Keep content separate from components.

## Design Principles
- Mobile-first and fully responsive.
- Modern, calm, professional, and accessible.
- Use neutral colours with only one main accent colour.
- Avoid excessive gradients, glassmorphism, glow effects, nested cards, and decorative clutter.
- Use clear typography hierarchy.
- Prefer IBM Plex Sans and IBM Plex Sans Thai.
- Follow an 8px spacing system.

## UX
- Navigation must remain clear on mobile and desktop.
- Every page must have one clear primary action.
- Use semantic HTML and correctly nested headings.
- Provide visible keyboard focus states.
- Respect prefers-reduced-motion.
- Images must have meaningful alt text.

## Quality
- Run npm run lint after changes.
- Run npm run build before declaring the work complete.
- Do not modify unrelated files.
- Summarise every changed file after completing a task.
